# LipatoS — Импорт актёров

Отдельный модуль для **Foundry VTT 14 / D&D 5e 6.0.5**. Добавляет в каталог «Актёры» кнопку **«Импорт актёра»** для ГМа. Модуль работает независимо от Character Forge, Laaru и сторонних библиотек.

## Использование

1. Откройте вкладку **Актёры → Импорт актёра**.
2. Вставьте JSON одного персонажа/монстра или массив JSON-объектов (до 50 за раз). Можно вставлять код с ограждением Markdown json.
3. Нажмите «Проверить и импортировать», проверьте список и подтвердите создание.
4. Актёры появятся в мире. Если актёр один, его лист откроется автоматически.

Ошибки JSON показываются до создания, исходный текст сохраняется в редакторе до успешного импорта. JavaScript не выполняется. Повторный импорт создаёт новых актёров, а не перезаписывает существующих.

## JSON

Основной формат — нативный JSON актёра Foundry (включая поля system, items, effects, prototypeToken, flags, img). Можно переносить данные из экспорта Foundry D&D5e 6.0.5 или присылать подготовленный в чате JSON.

Минимальный пример:

~~~json
{
  "name": "Скелет-маг",
  "type": "npc",
  "abilities": {"str": 8, "dex": 14, "con": 12, "int": 16, "wis": 10, "cha": 8},
  "saves": ["int", "wis"],
  "skills": {"arc": 2, "prc": 1},
  "hp": {"value": 45, "max": 45},
  "ac": 13,
  "movement": {"walk": 30, "units": "ft"},
  "cr": 4,
  "items": []
}
~~~

Полный пример лежит в [examples/skeleton-mage.json](examples/skeleton-mage.json).

Поддержка кратких полей:
- type: npc, character, монстр, нпс, персонаж;
- abilities: числовые значения str, dex, con, int, wis, cha либо объекты вида {"value": 12, "proficient": 1};
- saves: массив кодов характеристик со владением спасброском;
- skills: коды навыков D&D5e (например, arc, prc, ste) и степень владения 0/1/2/0.5;
- hp: число либо объект {value, max, temp};
- ac: числовая натуральная КД;
- movement: число (ходьба) либо объект с walk, fly, swim и units;
- cr: число или дробная строка "1/2";
- description: текст/HTML биографии;
- items: встроенные предметы с name, type, system и опционально img;
- features: дополнительные предметы типа feat, spells: дополнительные предметы типа spell;
- folder: ID существующей папки актёров или точное название папки;
- system: полные данные D&D5e (можно совмещать с сокращениями).

## BLFX-анимации атак (начиная с 1.1.0)

При включённом **Sequencer** импортёр автоматически воспроизводит анимации, записанные в флагах активности D&D5e 6.0.5. Пакет BLFX с нужными эффектами должен быть отдельно установлен и включён. Без Sequencer/BLFX обычный импорт продолжает работать. Перед броском выберите токен цели клавишей **T** и поместите токен атакующего на сцену. Анимация срабатывает после завершённого броска атаки (включая промах) и не срабатывает при отмене броска. После обновления модуля уже импортированные актёры с этими флагами не требуют повторного импорта.

Пример полей для одной активности типа `attack`:

~~~json
"flags": {
  "aindor": {
    "animation": {
      "databaseKey": "blfx.weapon.melee.natural.claw6.rend.attack1.color1",
      "durationMs": 1500,
      "trigger": "afterAttack",
      "target": "attackTarget",
      "provider": "sequencer-blfx"
    }
  }
}
~~~

Подсказки при отсутствии токена, цели, Sequencer или ресурса BLFX выводятся в Foundry. Анимации не меняют боевую механику и не означают попадание по цели. Модуль не включает и не распространяет платные ассеты.

**Важно:** импортёр не придумывает игровую механику за предметы. Чтобы атаки, урон, спасброски и заклинания действительно работали из листа, передавайте в их system полный совместимый блок activities (D&D5e 6.0.5), как в экспорте соответствующего предмета. Голые строки описания не создают кнопки бросков. Я могу готовить именно такие полные JSON-объекты отдельно для каждого монстра.

## Установка

Манифест для Foundry:

https://raw.githubusercontent.com/Lipatosha/LipatoS-actor-importer/main/module.json

ZIP автоматически публикуется в GitHub Releases при обновлениях main с номером версии из module.json. Если сборка не вышла, проверьте GitHub Actions. ZIP руками в репозиторий не кладём.

## Разработка

Основной код: scripts/main.js. Стили: styles/module.css. Изменения публикуются исключительно через Git. Модуль не содержит текстов или ассетов коммерческих D&D-книг.
